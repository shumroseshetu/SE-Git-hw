# SE-Git-hw

CINS 5318 Software Engineering - Assignment 1: Version Control using GitHub

## Project Overview

This repository was created to practice version control and collaboration using Git and GitHub. The project demonstrates repository management, commits, branching, pull requests, peer review, merge conflict resolution, and issue tracking.

## Project Files

- `hello.py` - Prints "Hello, World!" and was added as the initial program.
- `apple.py` - Prints "I eat apple" and was developed on the `feature-1` branch.
- `conflict-demo.txt` - Used to demonstrate and resolve a merge conflict.

## Branching and Feature Implementation

A separate branch named `feature-1` was created to develop the `apple.py` feature. The file was added, committed, and pushed to GitHub from this branch before being merged into the main branch through a pull request.

## Pull Request and Collaboration

A pull request was created to merge `feature-1` into `main`. Classmates reviewed the changes and provided feedback before the pull request was merged. I also reviewed a classmate's pull request and provided feedback as part of the collaboration process.

## Merge Conflict Resolution

A merge conflict was intentionally created by making different changes to the same content on separate branches. Git identified the conflicting changes, and the conflict was manually reviewed and resolved. The resolved version was then committed to the repository.

## GitHub Issues

GitHub Issues were used to organize and track project tasks. One issue was assigned to myself to document the completed GitHub workflow in this README. Another issue was assigned to a classmate to review the project files and GitHub documentation.These issues are used to track the assigned tasks until they are completed and verified.

## What I Learned

Through this assignment, I gained practical experience using Git and GitHub for version control and collaborative software development. I practiced creating and managing branches, making meaningful commits, working with pull requests and peer reviews, resolving merge conflicts, and using GitHub Issues to organize project tasks.
